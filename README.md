# Business Owner App v5.3.70

## Update
- Adds a **Move to In Process** action to customer cards, matching the existing prospect action.
- Moves the existing customer record into the prospect-side history as Flushed while creating or reusing its linked In the Process record at the PQI scheduled stage.
- Preserves the contact ID and existing details/history so converting the person back to a customer later updates the same contact instead of creating a duplicate.
- Opens the In the Process tab after a successful move.
- Retains the v5.3.69 Spouse Partnership functionality and all existing app features.

## Install
1. Extract this ZIP.
2. Upload/replace all files in the root of the existing GitHub Pages repository.
3. Commit the changes.
4. Close and reopen the installed app or refresh the website.
