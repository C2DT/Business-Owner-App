2. Set your weekly plan

Choose available days

3. Connect Google Calendar

One-time setup: create a Google OAuth Web client ID for your GitHub Pages site, then paste the client ID below. Never paste a client secret here. Authorization stays with Google; the access token is kept in memory and is not saved in app storage.

Your contact privacy

Your .vcf contact file is read inside this browser and is not uploaded to a server. Imported contacts, notes, and your schedule are stored on this device. If you choose to create Google Calendar events, the event details you approve are sent to Google Calendar.
